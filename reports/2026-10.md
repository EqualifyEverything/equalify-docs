**Reporting period:** Sep 1 – Oct 5, 2026

## Executive Summary

October was the team's most active month to date, with 29 tasks completed and 221 code commits across 7 repositories. The team closed out the FOSS deployment milestone and delivered dark mode, mobile layouts, and new site onboarding and CSV import features. It also improved how the platform handles scan failures, preserving results from the last valid scan rather than clearing blocker counts. Work on the Iris scanning engine accounted for the majority of commit volume and produced the first release of Equalify Iris for WordPress, which brings automated PDF accessibility tagging directly to WordPress sites.

## Highlights

- **Launched Equalify Iris for WordPress**, a new plugin that tags public PDFs in place, finds them anywhere site visitors can reach, and supports large site networks. It also keeps each PDF's icon linked to its accessible version and makes that icon screen-reader friendly.
- **Made scan results more resilient to failures.** When an audit-level scan fails, the platform now keeps data from the last valid scan instead of clearing blocker counts, and failed scans are clearly marked on the scans chart and table.
- **Added dark mode and mobile-friendly layouts** to improve usability across devices and viewing preferences.
- **Delivered site onboarding and CSV integration.** Features include automated site crawling, onboarding built into the Build Audit workflow, support for externally linked CSV files as a source of audit URLs (enabling WordPress plugin integration), and CSV-based user import.
- **Completed the FOSS deployment milestone**, including infrastructure provisioning scripts, a deployment strategy, deployment documentation, and a developer-focused introductory guide.

## Notable Events

- **Sep 9:** Responded to an external request for a public API. The team explained that an externally accessible API is not currently on the roadmap, largely because it would require a new, separate security layer.
- **Mid-September release:** Shipped a new version with improved scan timeout handling. An external user's bug report led the team to the underlying timeout issue, and on Sep 22 the team confirmed that the fix was included in the release from the previous week.
- **Sep 25:** Investigated a user-reported color contrast concern. The investigation found multiple instances of text on the site falling below the 4.5:1 WCAG contrast standard, which indicates the scan results were accurate. The partner noted that the user may have had difficulty matching flagged elements to the corresponding content on the page.
- **Sep 25 – Oct 2:** Investigated timeout errors on large scans. A user was unable to access past scan results through the chart because of the timeout error. The team identified scan size as the likely cause, and C. Aitken began a long-term fix.

## Risks & Blockers

- **Audit-level timeouts on large scans:** Large audits can exceed current timeout limits. In one reported case, this prevented a user from viewing past scan results. C. Aitken is increasing the audit-level timeout and making sure individual URL timeouts close out properly. As of Oct 2, the fix was expected to roll out within about a week.
- **Historical scan display issues:** Testing of the new historical scans feature found that the return link in the banner is the same color as the banner in dark mode. Some significantly older scans, possibly from before the current archiving architecture, also display inconsistently. Both issues are tracked for follow-up.
- **API access for external integrations:** External users have requested programmatic access. Supporting it would require a separate security layer, and the feature remains in the backlog for discussion.
- Add historical scans to the Detailed View. A dropdown will let users select a previous scan and review its archived blockers, with a banner to distinguish historical mode. *(C. Aitken)*
- Create a dedicated Recommendations view alongside the Summary View and Detailed View. All duplicate blocker grouping filters and logic will move into this view, along with a brief plain-language explanation. *(C. Aitken)*

### Recent Commit Highlights
