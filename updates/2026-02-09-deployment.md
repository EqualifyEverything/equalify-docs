# New Features & Bug Fixes — February 9, 2026

We've been busy! After reviewing feedback from the service team and our testers, we've deployed a round of new features and fixes. Here's what's new.

---

## New Features

- Audit Screen: Summary View
- Audit Screen: CSV Export
- Audit Screen: Blockers table now has user-settable columns
- Audit Screen: Blockers table is now searchable by URL or Blocker ID
- Audit Screen: Better visual feedback in audits that haven't run a scan
- Audit Screen: When scan is running, a progress bar is now shown instead of the chart
- Audit Screen: Added Y axis to graph
- Account: Now shows user role
- Individual blockers now have detail pages

---

## Bug Fixes

- Various styling issues and tweaks
- Fixed contrast issues in header/footer
- Fixes for scanning errors and work to prevent scans from hanging
- Fixed error with invitation domain
- Fixed error with changing schedule on audit screen
