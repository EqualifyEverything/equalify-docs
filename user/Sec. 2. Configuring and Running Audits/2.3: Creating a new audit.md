# Creating a new audit
Creating an audit is the first step in checking your website or documents for accessibility issues. In this section, you’ll learn how to set up a new audit, including tips for naming it clearly and adding URLs one at a time or in bulk. 
## Overview of the audit builder
Use the audit builder to set up recurring audits for your workspace. Once you configure these audits, all workspace members can access them.

To access the audit builder, from the main audits page, select "Add Audit." Selecting this option brings you to the "Audit Builder" page.
