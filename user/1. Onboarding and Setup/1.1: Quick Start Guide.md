# Quick Start Guide
Whether you are a product owner looking for accessibility insights or a developer looking to embed accessibility into your practice, this guide will help you get started with Equalify's platform. This section covers accessing the platform, navigating around, and helpful terms to become familiar with as you work within Equalify. Non-technical users should focus on Sections 1-2 for setup and high-level monitoring, while Developers should refer to Section 3 for technical review steps.
## Access & Onboarding
### Email invite
Once added, you will receive an email from noreply@equalify.uic.edu with the subject "You are invited to join Equalify". 

From the email invite, select "Accept Invite" to be redirected to the Equalify sign-in page. 

```tip
💡Tip: Managing a workspace’s access? See the 🔗”Manage User Access” page for more information about adding users to your team.
```

### Logging in
Depending on how your organization manages Equalify you can sign in using Single Sign-On (SSO) or Create a New Account, via the Sign Up for Equalify form.
#### Using SSO to Log In
If your organization has set up SSO for Equalify, log in using your existing credentials. 
```important
⚠️Important: You must have previously received an invitation to join Equalify for SSO to work.
```
<img src="https://github.com/EqualifyEverything/equalify-docs/blob/b724b4148ae2cc4c3f664114cffe3159130a881a/user/User%20Guide%20Images/Sec%201_Sign%20In.png" alt="Equalify sign-in page displaying the heading Sign in to Equalify, Sign in with SSO button, and a Create an account link for new users." width="500"/>

#### Creating a new account
If your organization does not have SSO set up for Equalify, select “Create an Account” and fill in your details. You must use the same email address that the invite was sent to.
```tip
💡Tip: Unsure if SSO is active for your organization? Ask your Equalify administrator for help.
```
